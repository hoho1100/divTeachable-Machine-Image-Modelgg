2. Arduino USB 연결

Arduino IDE의 시리얼 모니터를 먼저 닫은 뒤 연결하세요. 연결 버튼을 누르면 브라우저가 포트 선택 창을 엽니다.

아두이노 연결 안 됨

3. 모터 명령 테스트

AI와 별개로 번호를 직접 보내 모터를 테스트할 수 있습니다. 실제 쓰레기통을 장착하기 전에 확인하세요.

전송한 명령: 없음

4. AI 클래스와 쓰레기 종류 연결

모델의 실제 클래스 이름을 불러온 뒤, 각 쓰레기 종류에 해당하는 클래스를 선택하세요. 클래스 이름이 캔/종이/플라스틱/일반쓰레기와 정확히 같지 않아도 직접 선택할 수 있습니다.

안전장치: 설정한 신뢰도 이상으로 같은 분류가 연속 확인될 때만 명령을 보냅니다. 같은 종류가 계속 보일 때 모터 명령을 반복해서 보내지 않습니다.

모델을 불러오면 클래스 선택 항목이 나타납니다.
실행 조건: Chrome 또는 Edge에서 HTTPS 또는 localhost 주소로 열어야 카메라와 Web Serial이 작동합니다. 이 HTML은 인터넷 연결이 필요하며 Teachable Machine 모델을 온라인에서 불러옵니다.
중요: 모터 목표 위치는 기존 Arduino 코드의 1=0°, 2=90°, 3=180°, 4=270° 설정을 사용합니다. 원점 센서가 없으므로 전원을 켤 때 기구가 실제 0° 위치에 있는지 확인하세요. AI가 잘못 분류할 수 있으니 처음에는 통/기구를 장착하지 않고 시험하세요.
